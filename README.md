# 민방위 급수시설 점검 앱 — 독립 실행형(PWA) 패키지

이 폴더는 로그인 없이 누구나 쓸 수 있는 설치형 웹앱입니다. 모든 점검 자료와 사진은 **사용자 기기(브라우저)** 에 저장되며,
사용자 메뉴의 **자료 내보내기·가져오기(ZIP)** 로 담당자 간 자료를 주고받거나 서울시 담당자가 한 곳에 모을 수 있습니다.

## 1. 배포 방법 (셋 중 하나)

### A. 서울시 내부 웹서버 (권장)
이 폴더 전체(`index.html`, `sw.js`, `manifest.webmanifest`, `lib/`, `icons/`)를 웹서버의 한 폴더에 그대로 올리면 끝입니다.
- HTTPS 주소로 서비스해야 카메라 촬영·홈 화면 설치·오프라인 캐시가 모두 동작합니다(http://localhost 는 예외적으로 허용).
- 별도 서버 프로그램이나 DB는 필요 없습니다. 정적 파일만 있으면 됩니다.

### B. GitHub Pages (무료, 10분)
1. github.com 에서 새 저장소(예: `mbw-inspect`)를 만듭니다. (내부용이면 Private 저장소 + GitHub Pages 유료 플랜, 공개여도 되면 Public)
2. 이 폴더의 파일을 모두 업로드합니다. (`index.html` 이 저장소 최상위에 있어야 합니다)
3. 저장소 **Settings → Pages → Source: Deploy from a branch → main / (root)** 선택 후 저장.
4. 1~2분 뒤 `https://<계정명>.github.io/mbw-inspect/` 주소로 접속합니다.

### C. 파일로 바로 열기 (임시 확인용)
`index.html` 을 PC 크롬에서 더블클릭해도 동작합니다. 단, 이 방식은 오프라인 캐시(서비스워커)가 동작하지 않고, 스마트폰에서는 권장하지 않습니다.

## 2. 스마트폰 설치 (홈 화면에 추가)
- **Android(크롬)**: 주소 접속 → 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**
- **iPhone(사파리)**: 주소 접속 → 공유 버튼 → **홈 화면에 추가**
설치하면 전체 화면 앱처럼 실행되고, 한 번 연 뒤에는 통신이 끊겨도 앱이 열립니다(입력·사진은 기기에 보관).

## 3. 자료를 한곳에 모으는 방법
1. 자치구 담당자: 앱 오른쪽 위 **사용자 → 전체 내보내기(ZIP)** (시설별·점검별 내보내기는 시설 화면·보고서 화면에서)
2. ZIP 파일을 메일·메신저로 서울시 담당자에게 전달
3. 서울시 담당자: **사용자 → 가져오기(ZIP)** → 시설·점검·사진이 합쳐집니다. 같은 기록은 더 최근에 수정된 쪽이 유지됩니다.
4. 합친 뒤 **홈 → 엑셀 내려받기** 로 전체 현황 엑셀을 만들 수 있습니다.

## 4. claude.ai 게시 버전과의 차이
| 항목 | claude.ai 게시 버전 | 이 패키지 |
|---|---|---|
| 로그인 | 서울시 Claude 조직 계정 | 없음(누구나) |
| 자료 저장 | 공용 DB에 실시간 공유 | 각 기기에 저장, ZIP으로 교환 |
| 사진 | 공용 저장소 업로드 | 기기에 저장(ZIP에 포함) |
| 인쇄 | PDF 저장 후 인쇄 | 인쇄 버튼으로 바로 인쇄 |
| AI 사진 분류 | 지원 | 미지원(수동 분류) |
| 권한(관리자/담당자) | 공유 설정으로 구분 | 구분 없음 |

## 5. 주의
- 기기 브라우저의 사이트 데이터를 삭제하면 저장된 점검 자료도 지워집니다. 중요한 자료는 ZIP으로 내보내 보관하세요.
- 사진은 업로드 시 긴 변 1600px, JPEG로 줄여 저장합니다.
- HWPX(한글) 파일 생성은 지원하지 않습니다. PDF·엑셀을 제공합니다.
